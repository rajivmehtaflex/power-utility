# Knowledge-Bundle Research & Schema-Guided Querying

## When to Activate

- User provides a structured markdown knowledge bundle (index.md + subfolders) and asks to research, summarize, or extract information from it.
- User provides a schema documentation file and asks to query the corresponding database using it as a map.
- User has an OKF v0.2 bundle (markdown + YAML frontmatter, cross-linked concepts) and wants to visualize, explore, or interactively navigate it.
